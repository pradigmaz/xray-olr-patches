# Система обновлений Oblivion Lost Remake

Официальный репозиторий доставки обновлений и компонентов модификации **Oblivion Lost Remake**.

---

## Ветки обновлений (Каналы)

В лаунчере доступны два режима доставки обновлений:

* **Stable (Стабильная)** — текущая базовая версия игры. Включает только проверенные кумулятивные исправления. Рекомендуется для комфортного и стабильного прохождения.
* **Beta (Тестовая)** — экспериментальные сборки следующей версии. Предназначена для тех, кто хочет заранее опробовать новые механики и движковые фичи и **готов терпеть вылеты, косяки и нестабильность**.

---

## OLR Launcher (`OLR_Launcher.exe`)

Основной инструмент запуска игры и управления обновлениями.

**Возможности:**
* **Транзакционная установка**: проверка целостности файлов по контрольным суммам до внесения изменений.
* **Откат в 1 клик**: кнопка «Отменить последний патч» возвращает предыдущее рабочее состояние игры, если обновление не подошло.
* **Защита сейвов**: автоматическое резервное копирование сохранений при переключении на Beta-канал.
* **Аварийное восстановление**: починка файлов после сбоя сети, зависания или блокировки антивирусом.
* **Автообновление**: лаунчер обновляется автономно, не затрагивая файлы игры.
* **Настройка**: переключение рендеров, параметров запуска и сбор логов диагностики.

---

## Установка обновлений

* **Через лаунчер (рекомендуется)**: запустите `OLR_Launcher.exe` в папке игры, выберите желаемый канал и подтвердите обновление.
* **Вручную**: скачайте актуальный `olr_hotfix_cumulative.7z` со страницы [Releases](https://github.com/pradigmaz/xray-olr-patches/releases) и распакуйте в корень игры с заменой файлов *(при ручной установке функция автоматического отката недоступна)*.

---

## Сообщения об ошибках

Репорты по вылетам принимаются в официальных ресурсах сообщества **строго с прикреплённым логом вылета**:
* **Беседа ВК**: [Вступить в беседу](https://vk.me/join/TdgSEGCQCDr8nIjGb67DW24C2jimJnahE38=)
* **Тема на AP-PRO**: [Oblivion Lost Remake 3.0 Open Beta](https://ap-pro.ru/forums/topic/6654-oblivion-lost-remake-30-open-beta/)

**Правила оформления:**
* Лог находится по пути: `_appdata_\logs\xray_*.log` (или `openxray.log`).
* Сообщения без логов или без описания условий вылета не рассматриваются.
