# Кумулятивные хотфиксы текущего патча OLR

Репозиторий оперативных исправлений для текущего патча модификации **Oblivion Lost Remake**.

---

## Принцип накопления

- **Всё в одном архиве**: каждый релиз хотфикса (`Hotfix 1`, `Hotfix 2`, `Hotfix 3` и т.д.) включает в себя все предыдущие хотфиксы текущего патча плюс свежие доработки.
- **Постоянное имя файла**: актуальный архив всегда публикуется под именем **`olr_hotfix_cumulative.7z`** на странице [последнего релиза](https://github.com/pradigmaz/xray-olr-patches/releases/latest).
- **Для игрока**: не нужно ставить хотфиксы по цепочке — достаточно скачать последний релиз или обновиться через лаунчер. Совместимость сохранений сохраняется.

---

## Установка

### Автоматически (через лаунчер)
Запустите `OLR_Launcher.exe` в папке игры. При наличии нового хотфикса кнопка **«Обновить игру»** станет активной.

### Вручную
1. Скачайте [**olr_hotfix_cumulative.7z**](https://github.com/pradigmaz/xray-olr-patches/releases/latest/download/olr_hotfix_cumulative.7z).
2. Распакуйте архив в папку с игрой с заменой файлов.
3. Запустите игру через `OLR_Launcher.exe`.
