# Официальные кумулятивные хотфиксы для Oblivion Lost Remake 3.1

Данный открытый репозиторий предназначен для публикации официальных кумулятивных обновлений и улучшений модификации **Oblivion Lost Remake 3.1** (ветка разработки X-Ray OLR 3.x).

---

## 🧬 Принцип и формула кумулятивности

Все хотфиксы в этом репозитории формируются по строгому кумулятивному принципу:

- **Формула кумулятивного хотфикса**:
  \\text{Кумулятивный патч} = \\text{OLR 3.1.1} + \\text{Патч 3.1.2} + \\text{Патч 3.1.3} + \\text{Все фиксы текущей ветки}
- **Иерархия релизов**:
  Следующий крупный патч **OLR 3.1.4** по классическому канону разработки воберёт в себя абсолютно всю предыдущую цепочку (3.1.1 $\\to$ 3.1.2 $\\to$ 3.1.3 + все накопившиеся хотфиксы) плюс новые контентные и движковые улучшения.
- **Для игрока**:
  Не требуется искать и по очереди накатывать промежуточные хотфиксы или разбираться в версиях. Достаточно иметь базовый OLR 3.1 и установить **один единственный актуальный архив** olr_hotfix_cumulative.zip (или обновиться в один клик через OLR_Launcher.exe).
- **Сохранения**:
  Полная сквозная совместимость сохранений (*.sav) на протяжении всей линейки 3.1.x гарантирована.

## 📥 Скачивание и установка

### Способ 1: Автоматическое обновление через лаунчер (Рекомендуется)
1. Запустите **OLR_Launcher.exe** в корневой папке игры.
2. Лаунчер автоматически свяжется с репозиторием и проверит наличие обновлений.
3. При наличии свежего хотфикса в шапке окна станет активна кнопка **[ ОБНОВИТЬ ИГРУ ]**. Нажмите её — лаунчер сам загрузит, проверит целостность и применит обновление с отображением прогресса и скорости загрузки.

### Способ 2: Ручная установка
1. Скачайте актуальный кумулятивный архив со страницы [последнего релиза](https://github.com/pradigmaz/xray-olr-patches/releases/latest) (прямая постоянная ссылка: [**olr_hotfix_cumulative.zip**](https://github.com/pradigmaz/xray-olr-patches/releases/latest/download/olr_hotfix_cumulative.zip)).
2. Распакуйте содержимое архива в корневую директорию установленной игры **OLR 3.1** с подтверждением замены файлов.
3. Запустите игру через **OLR_Launcher.exe**.
