# Официальные кумулятивные хотфиксы для Oblivion Lost Remake 3.1

Данный открытый репозиторий предназначен для публикации официальных кумулятивных обновлений и исправлений модификации **Oblivion Lost Remake 3.1** (ветка разработки X-Ray OLR 3.x).

---

## 🧬 Принцип и формула кумулятивности

Все хотфиксы в этом репозитории формируются по строгому кумулятивному принципу:

- **Формула кумулятивного хотфикса**:
  `Кумулятивный патч = OLR 3.1.1 + Патч 3.1.2 + Патч 3.1.3 + Все фиксы текущей ветки`

- **Иерархия релизов (рекурсивный кумулятивный закон)**:
  Кумулятивный принцип рекурсивен и распространяется на абсолютно все будущие версии:
  `Кумулятивный патч 3.1.N = 3.1.1 + 3.1.2 + ... + 3.1.(N-1) + хотфиксы текущей ветки`
  - **OLR 3.1.4**: по классическому канону разработки монолитно воберёт в себя абсолютно всю предшествующую цепочку (`3.1.1` → `3.1.2` → `3.1.3`) + все накопившиеся хотфиксы текущей ветки в единый неделимый фундамент.
  - **OLR 3.1.5**: точно так же монолитно воберёт в себя всю цепочку (`3.1.1` → `3.1.2` → `3.1.3` → `3.1.4`) + хотфиксы.

- **Для игрока**:
  Не требуется искать и по очереди накатывать промежуточные хотфиксы или разбираться в версиях. Достаточно иметь базовый OLR 3.1 и установить **один единственный актуальный архив** `olr_hotfix_cumulative.7z` (или обновиться в один клик через `OLR_Launcher.exe`).

- **Формат архивации и сжатие**:
  Все кумулятивные архивы упаковываются исключительно в формат **`.7z` с максимальным сжатием** (`-mx=9`, LZMA2).

- **Сохранения**:
  Полная сквозная совместимость сохранений (`*.sav`) на протяжении всей линейки 3.1.x гарантирована.

## 📥 Скачивание и установка

### Способ 1: Автоматическое обновление через лаунчер (Рекомендуется)
1. Запустите **OLR_Launcher.exe** в корневой папке игры.
2. Лаунчер автоматически свяжется с репозиторием и проверит наличие обновлений.
3. При наличии свежего хотфикса в шапке окна станет активна кнопка **[ ОБНОВИТЬ ИГРУ ]**. Нажмите её — лаунчер сам загрузит, проверит целостность и применит обновление с отображением прогресса и скорости загрузки.

### Способ 2: Ручная установка
1. Скачайте актуальный кумулятивный архив со страницы [последнего релиза](https://github.com/pradigmaz/xray-olr-patches/releases/latest) (прямая постоянная ссылка: [**olr_hotfix_cumulative.7z**](https://github.com/pradigmaz/xray-olr-patches/releases/latest/download/olr_hotfix_cumulative.7z)).
2. Распакуйте содержимое архива в корневую директорию установленной игры **OLR 3.1** с подтверждением замены файлов (в архиве уже есть паспорт `patch_version.ini`, поэтому лаунчер автоматически распознает ручную установку).
3. Запустите игру через **OLR_Launcher.exe**.
